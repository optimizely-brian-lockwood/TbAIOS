# Initiative Template

Copy this directory to `initiatives/[initiative-id]-[name]/` when onboarding a new initiative
phase or sub-initiative.

## How to use

1. Copy this directory: `cp -r initiatives/_template initiatives/[your-initiative-id]/`
2. Rename the files as appropriate
3. Fill in the `initiative-brief.md` with the initiative's definition
4. Create the records structure: `mkdir -p docs/records/{program,pending,waves,milestones,inputs,data,reference}`
5. Register the initiative in `initiatives/registry.md`

## Template files

- `initiative-brief.md` — initiative definition, scope, goals, current phase
- `wave-plan.md` — planned wave structure and deliverables
